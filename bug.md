# Bug du compteur

Ce que je vois :
Le chiffre affiché à l'écran reste à 0 lorsque je clique sur le bouton "+1".

Ce que j’attendais :
Le chiffre dans la console s'incremente de 1 à chaque fois que j'appuye sur le bouton. Je m'attendais donc à voir le nombre augemnter de 1 chaque fois.

La boîte qui change :
La variable JavaScript (par exemple `compteur` ou `n`) qui stocke la valeur en mémoire.

Ce qui ne se met pas à jour :
L'élément du DOM (le texte de la balise HTML à l'écran).
