# Audit daltonisme et basse vision

**Projet :** Sentia
**Méthode :** vérification de l'interface avec les déficiences visuelles simulées.

## 1. Vérification

Les interfaces ont été vérifiées avec une simulation du daltonisme.

Profils concernés :

* Deutéranopie
* Protanopie
* Tritanopie

L'objectif était de vérifier que les informations importantes restent compréhensibles sans dépendre uniquement de la couleur.

## 2. Résultats

Les éléments importants utilisent également du texte, des icônes ou des formes pour transmettre l'information.

Les états positifs et négatifs ne reposent donc pas uniquement sur le vert ou le rouge.

Le test de perception des couleurs effectué pendant les tests utilisateurs n'a pas montré de problème bloquant.

## 3. Corrections

Aucune correction bloquante n'a été nécessaire après la vérification.

Les informations importantes restent compréhensibles même lorsque les couleurs sont moins facilement distinguables.

## 4. Vérification finale

* [x] Deutéranopie vérifiée
* [x] Protanopie vérifiée
* [x] Tritanopie vérifiée

* [x] Aucun problème bloquant identifié

## Conclusion

L'interface reste compréhensible avec les différents profils de daltonisme testés.

Aucune correction majeure n'est nécessaire pour ce critère.
